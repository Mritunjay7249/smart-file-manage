# Smart File Manager

Ek desktop file management app jo Python aur PyQt6 se banayi gayi hai — files organize karna, duplicates dhundhna, tagging, encryption, aur automation sab ek jagah.

## Features

- 📁 Auto file organizer (type ke basis par)
- <img width="952" height="499" alt="Screenshot 2026-08-01 221536" src="https://github.com/user-attachments/assets/2b09027c-fc7d-4466-a83a-196e2de354c9" />

- 🔍 Duplicate file finder (hash-based)
- ✏️ Bulk rename tool
- 👁️ File preview
- 🏷️ Smart tagging aur search (SQLite database)
- 📊 Storage analyzer
- 🕒 Old/unused file detector
- 🔎 Advanced multi-filter search
- 🧹 Automated cleanup rules
- 📂 Real-time folder watcher
- 🔒 File encryption/decryption
- 🗑️ Leftover app finder aur temp file cleaner
- 🎨 Custom background support

## Tech Stack

- Python 3.13
- PyQt6 (GUI)
- SQLite (database)
- watchdog (file monitoring)
- cryptography (encryption)
